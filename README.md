# comic-wheel-pager

漫画サイトのページャーをホイールで操作できるようにするブラウザ拡張機能です。

## 対応サイト

- championcross.jp
- comic-action.com
- comic-earthstar.com
- comic-fuz.com
- comic-gardo.com
- comic-medu.com
- comic-walker.com
- pocket.shonenmagazine.com
- shonenjumpplus.com
- youngchampion.jp
- g-comi.jp
